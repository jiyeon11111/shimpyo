# 체감온도 모델 추가 분석 (2026-11-24)

기획서 4장 모델 부분 보강용. 코드는 `모델강조_추가분석.py`(코랩 1칸), 모델 재학습 없음.
조건은 4장 최종 시험과 같다: 같은 전처리, 정답 = 보정 정답(센서 측정 편차 제거) 33℃ 이상, 2026년 여름은 학습·편차 계산에 쓰지 않음.

## 1. 변수 중요도 (`변수중요도_최종모델.csv`)

최종모델(차이_보정, 2021~2025 재학습)의 변수 58개. LightGBM gain과 SHAP 평균 절댓값(2021~2025 표본 5천 행)을 같이 적었다.
모델은 "가장 가까운 AWS 체감온도와의 차이"를 예측하므로, SHAP은 그 차이를 얼마나 움직이는지(℃)로 읽는다.

| 묶음 | gain 비율 | SHAP 비율 |
|---|---|---|
| 관측소 실시간 값 (AWS 3곳·ASOS·기준선) | 52.7% | 67.8% |
| 장소 특징 (토지피복·건물·도로·위치) | 40.2% | 24.3% |
| 시간 (시·연중일·요일·월) | 7.1% | 7.9% |

- gain 상위: 가까운 AWS 체감온도, ASOS 체감온도, 기준선, 시각, 경도·위도, ASOS 습도, AWS 2·3 체감온도, 반경 100m 건물비율
- 장소 특징 중 상위: 반경 100m 건물비율(10위), 반경 300m 도로밀도(15위), 가까운 큰길·도로까지 거리, 반경 100m 평균층수, 시가지 비율

## 2. 단순 보정과 비교, 2026 시험 (`단순보정비교_2026.csv`)

- 관측소: 센서에서 가장 가까운 AWS 체감온도 (4장 표의 '관측소'와 같은 값)
- 단순 보정: 관측소 + 시간대별 평균 편차 (2021~2025로만 계산, `단순보정_시간별편차.csv`)
- AI: 최종모델(차이_보정)

| 범위 | 방법 | MAE(℃) | 미탐지율 33℃ | 미탐지율 32℃ | 오탐지율 32℃ |
|---|---|---|---|---|---|
| 서울 센서 전체 (235만 행) | 관측소 | 0.982 | 42.8% | 21.2% | 2.39% |
| | 단순 보정 | 0.892 | 39.1% | 18.2% | 2.94% |
| | AI | **0.562** | 28.0% | **8.2%** | 2.89% |
| 관악구 센서 (16.5만 행) | 관측소 | 1.097 | 34.5% | 21.7% | 3.60% |
| | 단순 보정 | 1.040 | 32.6% | 20.0% | 4.16% |
| | AI | **0.565** | 21.1% | **4.9%** | 3.38% |

- 단순 보정은 MAE를 약 9%(서울)·5%(관악)만 줄인다. AI는 43%(서울)·48%(관악) 줄인다.
- 판정선 32℃ 미탐지율: 단순 보정 18.2% vs AI 8.2%(서울), 20.0% vs 4.9%(관악). 오탐지율은 AI가 단순 보정보다 낮거나 같다.
- 시간대 편차만으로는 동네마다 다른 더위(건물·도로·지형)를 못 잡는다는 뜻. 장소 특징의 gain 비중 40%와 맞는다.

## 3. 관악구 행정동별 (`단순보정비교_2026_관악동별.csv`, 판정선 32℃)

센서가 있는 21개 동 전부. 정답 실측값은 S-DoT 센서 지점에만 있으므로 동 안의 센서 지점 기준이다(동별 센서 1~8개).

- MAE: 21개 동 모두 AI가 단순 보정보다 낮음
- 미탐지율: 17개 동에서 AI가 단순 보정 이하. 나머지 4개 동(청림·성현·조원·미성)은 둘 다 7% 이하로 낮은 곳
- 관측소가 가장 많이 놓친 동: 서림동 63.3% → AI 12.1%, 대학동 60.6% → 19.1%, 낙성대동 49.3% → 2.5%, 삼성동 38.4% → 9.5%

## 확인 사항

- 4장 표와 일치 확인: AI 32℃ 미탐지 8.17%(4장 8.2%), MAE 0.982 / 0.562 동일. 관측소 33℃ 미탐지는 42.81%로 4장 42.85%와 0.04%p 차이(정답 33℃ 이상 행 수가 132,635 vs 132,727로 근소하게 다름, 측정 편차 표 반올림 차이로 보임). 결론에는 영향 없음.
- 팀 PDF 4쪽의 "관악구 폭염 시간 21.7% 미탐지"는 위 표의 관악구 센서·관측소·판정선 32℃ 값(21.68%)과 같은 숫자다. 10쪽의 42.9%는 서울 전체·판정선 33℃ 값이라 서로 다른 조건이다.
