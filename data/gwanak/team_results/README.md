# 2차 심사 보완 분석 결과 (김아현, 2026-11-22)

**모두 가상 라이더 1,000명(관악구) 시뮬레이션 결과다.** 실제 배달 기록이 아니므로 발표·기획서에 "가상 라이더"라고 밝힌다.

코드: `../team_scripts/run_k.py` (규칙은 `run_final.py`와 같고 활동일 기준만 바꿈)

```
python run_k.py opps_2026_model.csv.gz 가상라이더_관악_라이더.csv
```

`opps_2026_model.csv.gz`(34MB)는 git에 올리지 않는다. 팀 드라이브 `쉼표_데이터파일/가상라이더_관악/분석3_계산자료`에서 받는다.

## 규칙과 가정

- 모델 체감온도 32℃ 이상, 최근 2시간 배달 이동 60분 이상, 시간대별 최근 28일 중 K일 이상 근무
- 쉬면 30분치 지급(평소 시급 × 30/60), 하루 4번까지
- 자격이 되는 배달 완료 순간마다 확률 P로 쉼(P = 1.0, 0.5, seed 1)
- 기준값 확인: K=12, P=1.0 → 24,941회·1.472억 / P=0.5 → 19,500회·1.144억 (1,000명당, run_final.py와 같음)

## 파일

| 파일 | 내용 |
|---|---|
| 활동일_변경_지급.csv | K = 12·10·8일, P = 1.0·0.5별 지급 횟수, 받은 라이더, 1,000명당 총액, 관악구 환산(2,500 / 4,700 / 7,200명) |
| 활동일_변경_유형별.csv | 같은 조건의 유형별(전업·저녁부업·점심주말) 받은 비율, 1인 평균·중앙 지급액, 평균 횟수 |
| 유형별_지급예시_K12_P05.csv | K=12, P=0.5에서 유형별 대표 라이더(여름 지급액 중앙값에 가장 가까운 라이더) |
